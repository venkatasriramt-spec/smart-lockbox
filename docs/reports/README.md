# Reports

This folder contains the written reports produced over the course of the project. Each is provided as both the original `.docx` and a converted `.pdf` for easy previewing on GitHub.

| File | Description |
|---|---|
| **Smart_Lockbox_Combined_Report.docx / .pdf** | The consolidated Review 1 + Review 2 + Review 3 report submitted to faculty for final evaluation (scored 29/30). This is the most complete and up-to-date technical writeup of the project — architecture, data handling, algorithm design, sensor calibration, test cases, performance metrics, and comparison with commercial alternatives. |
| **IEEE_Report.pdf** | A conference-style paper written up from the project, submitted to faculty as part of a conference-paper application. |
| **IDF-B_Invention_Disclosure.docx / .pdf** | An Invention Disclosure Format (IDF-B) document submitted to faculty as part of a patent application, covering novelty analysis against prior art and recommended IP protection scope. |

**Status note:** The IEEE conference paper and the patent invention disclosure were submitted through the institution's faculty review process. As of this writing, no response has been received yet from the relevant conference or patent body — these should be treated as *submitted*, not as accepted, published, or granted.
